# Notes

Handwritten notes and exercise answers, **versioned in git**. They record how I learned each
concept. If I can't explain it in writing, I don't master it.

## Organization
- One file per subchapter, with the same prefix as in [`learnPlan/`](../learnPlan/00-INDICE.md):
  `01a-http.md`, `01b-architecture.md`, `01c-cors.md`…
- **Project deliverables** don't go here, but wherever each chapter says (`docs/api/contract.md`,
  `docs/mvp.md`, `docs/architecture/`…). They are living documentation, not notes.

## File structure
```markdown
# 01a — HTTP and the client-server model

## Concepts (in my own words)

## Self-assessment questions
### 1. ...

## Exercise 1 — Dissect a real request
(command output in code blocks, my analysis below)

## Open questions
```

## Commits
One commit per finished exercise, e.g. `docs(notes): 01a exercise 1 - curl dissection`.
